# Primitive DB

Проект по созданию примитивной реляционной базы данных (СУБД) на языке Python. Выполнен в рамках модульной процедурной архитектуры без использования объектно-ориентированного программирования (ООП).

## Используемые технологии

* **Python** (версия >= 3.12)
* **uv** — менеджер пакетов и окружения
* **Ruff** — линтер для контроля качества кода (соответствие стандартам PEP 8)
* **shlex** — встроенный модуль для безопасного разбора команд пользователя

## Установка и запуск

Пакет спроектирован как автономная утилита командной строки (CLI).

1. **Сборка пакета:**
   ```bash
   uv build
   ```

2. **Локальная установка инструмента в систему:**
   ```bash
   uv tool install dist/*.whl
   ```

3. **Запуск программы из терминала:**
   ```bash
   project
   ```

## Управление таблицами

Приложение работает в интерактивном консольном режиме (REPL-цикл). Доступны следующие операции для управления структурой базы данных:

* `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип>...` — Создать новую таблицу. Каждой таблице автоматически добавляется первый столбец `ID` с типом `int`. Поддерживаемые типы данных: `int`, `str`, `bool`.
* `list_tables` — Показать список всех существующих таблиц в текущей базе данных.
* `drop_table <имя_таблицы>` — Полностью удалить указанную таблицу из метаданных.
* `help` — Вывести встроенную справочную информацию по командам.
* `exit` — Аккуратно завершить работу программы.

### Пример сессии работы:
```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

Вся информация о структуре таблиц сохраняется в корневом файле `db_meta.json`.
