# Примитивная база данных

Проект по созданию примитивной реляционной базы данных (СУБД) на языке Python. Выполнен в рамках модульной процедурной архитектуры без использования объектно-ориентированного программирования (ООП).

Запись полного сценария работы с таблицами в Asciinema — [по ссылке](https://asciinema.org/a/1IZFBHw7WtO5QJ4U). Ниже в отдельных блоках есть ссылки на записи по отдельным темам.

## Используемые технологии

* **Python** (версия >= 3.12)
* **uv** — современный менеджер пакетов и окружения
* **Ruff** — линтер для контроля качества кода (соответствие стандартам PEP 8)
* **shlex** — встроенный модуль для безопасного разбора команд пользователя
* **prettytable** — библиотека для форматированного ASCII-вывода таблиц в консоль

## Установка и запуск

Пакет спроектирован как автономная утилита командной строки (CLI).

### Вариант 1: запуск напрямую через менеджер пакетов
```bash
uv run database
```

### Вариант 2: локальная сборка и установка в систему

1. **Сборка пакета:**
   ```bash
   uv build
   ```

2. **Установка инструмента:**
   ```bash
   uv tool install dist/*.whl
   ```

3. **Запуск из терминала:**
   Для запуска можно использовать любую из двух команд:
   ```bash
   database
   ```
   или
   ```bash
   project
   ```

## Управление таблицами и данными

Приложение работает в интерактивном консольном режиме (REPL-цикл). Доступны следующие операции СУБД:

### Общие команды:
* `info <имя_таблицы>` — Вывести информацию о столбцах таблицы и их типах.
* `help` — Вывести справочную информацию по командам.
* `exit` — Завершить работу программы.

### Структура таблиц:
* `create_table <таблица> <ст1:тип> <ст2:тип>...` — Создать новую таблицу. Каждой таблице автоматически добавляется первый столбец `ID:int`, если он не был явно задан пользователем. Поддерживаемые типы данных: `int`, `str`, `bool`.
* `list_tables` — Показать список всех существующих таблиц.
* `drop_table <имя_таблицы>` — Полностью удалить указанную таблицу.

### CRUD-операции:
* `insert into <таблица> values (<значение1>, <значение2>, ...)` — Создать новую запись в таблице с автоматическим расчётом ID. Строковые значения обязательно должны передаваться в кавычках.
* `select from <таблица> [where <столбец> = <значение>]` — Прочитать записи из таблицы. При наличии условия `where` выполняет фильтрацию. Выводит данные в виде ASCII-графики.
* `update <таблица> set <столбец1> = <новое_значение> [where <столбец_условия> = <значение>]` — Обновить данные в строках, соответствующих условию.
* `delete from <таблица> [where <столбец> = <значение>]` — Удалить записи из таблицы по условию (требуется подтверждение).

### Дополнительные возможности:
* **Централизованная обработка ошибок:** Использованы декораторы для перехвата исключений (`ValueError`, `KeyError`, `FileNotFoundError`). 
* **Подтверждение действий:** Реализована фабрика декораторов для безопасного выполнения опасных операций (`drop_table` и `delete`). 
* **Замер времени выполнения операций:** Добавлен декоратор замера времени выполнения для медленных операций ввода-вывода (`insert` и `select`). 
* **Кэширование на замыканиях:** Реализовано сохранение результатов повторных одинаковых запросов `select` без чтения с жёсткого диска.
